# Backtest Screenshots

This directory is where you can add visual proof of backtest results.

## Suggested additions

Drop screenshots of:

1. **Strategy Tester backtest reports** — final OnTester() output for each configuration
2. **Equity curves** — chart from Strategy Tester → Graph tab
3. **Live dashboard screenshots** — the on-chart dashboard showing SYSTEM: ACTIVE
4. **Live trade history** — MT5 History tab with winners/losers visible
5. **Audit CSV samples** — Excel view of the 23-column audit trail

## Naming convention

`YYYY-MM-DD_<description>.png`

Examples:
- `2026-07-02_v4_path_h_6mo_backtest.png`
- `2026-07-15_v5_path_d_walkforward.png`
- `2026-08-14_live_dashboard_friday.png`

## For recruiters/reviewers

Screenshots will be most helpful here if they clearly show:
- Date range of backtest
- Final metrics (Net PnL, PF, DD, Win Rate)
- Trade count
- The specific EA version in the title bar

## Privacy note

Before uploading any screenshot:
- Blur out account numbers (top-left of MT5)
- Blur out broker-specific balance figures if desired
- Keep the actual metrics visible
